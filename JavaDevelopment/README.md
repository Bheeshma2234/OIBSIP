# Projects

## Task 1 – Online Reservation System

A Java-based console application designed to simulate an online ticket reservation system.

### Features

- User login
- Passenger information
- Journey details
- Ticket reservation
- Reservation details
- Ticket cancellation
- Exit option

### Concepts Used

- Classes and Objects
- Methods
- Constructors
- User Input
- Conditional Statements
- Loops
- Exception Handling
- Menu-Driven Programming

## Task 2 – Number Guessing Game

An interactive Java game where the computer generates a random number and the user attempts to guess the number.

### Features

- Random number generation
- User guessing
- Higher or lower hints
- Attempt counting
- Score calculation
- Replay option

### Concepts Used

- Random Number Generation
- Loops
- Conditional Statements
- Variables
- Methods
- User Input

---

## Task 3 – ATM Interface

A Java-based console application that simulates common ATM operations.

### Features

- User authentication
- Balance enquiry
- Cash withdrawal
- Cash deposit
- Transaction processing
- Input validation
- Exit option

### Concepts Used

- Classes and Objects
- Encapsulation
- Methods
- Conditional Statements
- Loops
- Exception Handling
- Menu-Driven Programming
