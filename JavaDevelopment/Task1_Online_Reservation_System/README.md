# Task 1 – Online Reservation System

## Objective

To develop a Java-based Online Reservation System that allows users to perform basic ticket reservation operations.

---

## Description

The Online Reservation System is a console-based Java application designed to demonstrate Java programming concepts and Object-Oriented Programming.

The system allows users to enter passenger information, journey details, reserve tickets, view reservation information, and cancel reservations.

---

## Features

### User Login

The system provides a basic login mechanism before allowing the user to access reservation operations.

### Ticket Reservation

Users can enter details such as:

- Passenger Name
- Age
- Gender
- Source
- Destination
- Journey Details

### Reservation Details

The application displays the reservation information entered by the user.

### Ticket Cancellation

Users can cancel an existing reservation.

### Exit

The user can exit the application safely.

This project provides practical experience in Java programming, Object-Oriented Programming, user input handling, menu-driven applications, and basic reservation-system logic.
