# Projects

## Task 1 – Iris Flower Classification

A machine learning project that classifies iris flowers into different species based on their physical measurements.

### Features

- Dataset loading
- Data preprocessing
- Exploratory Data Analysis
- Feature analysis
- Data visualization
- Machine learning model training
- Flower species prediction
- Model evaluation

### Dataset

The Iris dataset contains measurements of iris flowers including:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The target classes are:

- Iris-setosa
- Iris-versicolor
- Iris-virginica

### Concepts Used

- Classification
- Data Preprocessing
- Exploratory Data Analysis
- Data Visualization
- Machine Learning
- Model Evaluation

## Task 3 – SMS Spam Detection

A machine learning project that classifies SMS messages as either spam or legitimate (ham).

### Features

- SMS dataset loading
- Text preprocessing
- Data cleaning
- Text feature extraction
- Spam and ham classification
- Machine learning model training
- Message prediction
- Model evaluation

### Dataset

The dataset contains SMS messages labeled as:

- Ham
- Spam

### Text Processing

The project performs text preprocessing techniques such as:

- Removing unnecessary characters
- Text normalization
- Tokenization
- Feature extraction
- Converting text into numerical features

### Machine Learning

Machine learning classification techniques are used to identify whether an SMS message is spam or legitimate.

### Evaluation

The model is evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

### Concepts Used

- Natural Language Processing
- Text Classification
- Data Preprocessing
- Feature Extraction
- Machine Learning
- Model Evaluation
