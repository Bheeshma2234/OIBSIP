5. Analysis of Open Ports
-----------------------------------------------------------

Port 135 (MSRPC)
Purpose:
Microsoft Remote Procedure Call used by Windows services.

Security Risk:
If exposed to untrusted networks, attackers may attempt to exploit Windows services.

-----------------------------------------------------------

Port 139 (NetBIOS)
Purpose:
Used for Windows file and printer sharing.

Security Risk:
Can expose shared resources if not properly secured.

-----------------------------------------------------------

Port 445 (Microsoft-DS / SMB)
Purpose:
Windows file sharing protocol.

Security Risk:
Frequently targeted by malware and ransomware if left exposed.

-----------------------------------------------------------

Port 3306 (MySQL)
Purpose:
Database server communication.

Security Risk:
Database services should not be publicly accessible without strong authentication and firewall protection.
