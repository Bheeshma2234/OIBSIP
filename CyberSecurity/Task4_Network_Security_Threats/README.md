# Task 4 – Research Report: Common Network Security Threats

## Objective

The objective of this task is to study and understand the most common network security threats, their working principles, real-world impact, and effective mitigation strategies. This report aims to improve awareness of modern cyber attacks and the importance of implementing strong security controls to protect network infrastructure.

---

## About Network Security

Network security is the practice of protecting computer networks and connected devices from unauthorized access, misuse, cyber attacks, and data breaches. It involves implementing policies, technologies, and security measures that ensure the confidentiality, integrity, and availability of information.

---

## Topics Covered

This report includes detailed information about the following network security threats:

- Denial of Service (DoS)
- Distributed Denial of Service (DDoS)
- Man-in-the-Middle (MITM) Attacks
- IP Spoofing
- DNS Poisoning (Bonus Topic)
